produced during the verification campaign. File names cited in them refer to
the pre-release working tree: `rigidity_paper_v2.tex` is now
`paper/rigidity-symmetric-holomorphic.tex`, and `rigidity_paper.tex` /
`rigidity_paper_corrected.tex` were retired (the latter is the over-claiming

cited in them are label-order counts, not the compiled numbering of the
published paper. The authoritative statement-by-statement correspondence is
the table in the repository README and in the header of
`lean/RequestProject/Main.lean`.
